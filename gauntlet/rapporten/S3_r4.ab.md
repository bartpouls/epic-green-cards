# S3 r4 — blinde A/B (stuk data-e2)

Methode: `gauntlet/rapporten/S3_r4_scripts/ab4.js` leest de bron-zinnen letterlijk uit `casus-uwi.md` sectie 5 (het script faalt als een zin niet in sectie 5 staat) en laat de spel-kant door de ECHTE Engine + Predicaten + data produceren (scenario's gespeeld via `Engine.speelKaart`/`volgendeDag`, feedbackvraag/zichtbaar/profiel door `Predicaten.evalueer` op de data-predicaten). Per paar is X/Y met `crypto.randomInt` toegewezen; de sleutel staat in `S3_r4.sleutel.json`. De paren zelf staan in `S3_r4.paren.md` (zonder sleutel). 22 paren (vereist: 10).
